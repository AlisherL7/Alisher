# Курс «Анализ акций: путь от нуля до продвинутого уровня»

Учебная система для самостоятельного обучения анализу акций с нуля до продвинутого уровня.

## Файлы

| Файл | Что это |
|---|---|
| `Анализ акций — путь от нуля до продвинутого уровня.md` | Полный учебник (13 уровней, ~22 500 слов): объяснения, формулы, пошаговые расчёты, задания, контрольные вопросы, мини-тесты с ответами, чек-лист, словарь EN→RU, источники, видеотека |
| `Анализ акций — путь от нуля до продвинутого уровня.docx` | Тот же учебник в формате Word с автособираемым оглавлением |
| `Трекер обучения анализу акций.xlsx` | Рабочий трекер: 8 листов с формулами, выпадающими списками и условным форматированием |
| `build_tracker.py` | Скрипт, которым собран XLSX (для пересборки после правок) |

## Листы трекера

1. **Dashboard** — прогресс общий и по уровням, серия учебных дней, рекомендуемый следующий шаг (всё на формулах) и 3 графика: прогресс по уровням, часы по уровням, распределение статусов
2. **Roadmap** — 70 этапов программы, уровни 0–12
3. **Glossary** — 40 ключевых терминов с самооценкой и датами повторения
4. **Video Library** — проверенные образовательные каналы и материалы
5. **Practice Log** — журнал практики (первая строка — пример заполнения)
6. **Company Analysis** — шаблон разбора компании из 17 разделов
7. **Review Calendar** — интервальное повторение 1 / 3 / 7 / 14 / 30 дней
8. **Sources** — официальные источники данных

Цвет текста в трекере: **синий** — заполняете вы, **чёрный** — формулы, **жёлтая заливка** — ключевое поле.

## Как начать

1. Открыть трекер, вписать дату начала обучения в `Dashboard!B5`.
2. Открыть учебник, прочитать разделы 0.1–0.2 и 0.6.
3. Выполнить задание Уровня 0 и внести результат в `Practice Log`.
4. Дальше следовать плану первой недели (в конце учебника).

## Пересборка XLSX

```bash
pip install openpyxl
python3 build_tracker.py
```

## Чем открывать

Файл использует условное форматирование, полосы прогресса, выпадающие списки и графики. Полностью это поддерживают **Excel**, **LibreOffice Calc** (бесплатно с libreoffice.org) и **Google Таблицы**. **Numbers** при открытии удаляет часть условного форматирования — предупреждение об этом нормально, формулы и графики не страдают, но пересохранять файл из Numbers не стоит.

## Ограничение

Материалы носят образовательный характер и не являются инвестиционной рекомендацией.
