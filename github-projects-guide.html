🚀 GitHub Open-Source Проекты

Пошаговый гайд — как запустить готовые проекты с GitHub и зарабатывать на них

📚 Шаг 0 — Что нужно знать сначала

  • 1
    Зарегистрируйся на GitHub — github.com. Это бесплатно. Здесь хранятся все проекты.
  • 2
    Установи Git на свой компьютер — git-scm.com/downloads. Это программа для скачивания кода.
  • 3
    Fork (форк) — это твоя личная копия чужого проекта. Нажми кнопку Fork на странице репозитория в GitHub — и проект появится в твоём аккаунте.
  • 4
    Clone (клонирование) — скачать код на свой компьютер.
    git clone https://github.com/ТВО_ИМЯ/НАЗВАНИЕ_ПРОЕКТА
  • 5
    Хостинг для запуска — тебе нужен сервер. Самый простой старт: Railway или Render — оба бесплатны для начала. Для серьёзных проектов — DigitalOcean (~$6/мес).
📅 Cal.diy
Аналог Calendly — сервис записи на встречи
⭐ 45k stars

Что это такое

Calendly берёт $12–16/мес с каждого пользователя. Cal.diy — тот же функционал, но open-source. Ты ставишь его, делаешь white-label (своё название, свой домен) и продаёшь доступ специалистам: стоматологам, юристам, репетиторам.

💰 Потенциал: 5 000–15 000 ₽/клиент в месяц

Как запустить

# 1. Открой в браузере:
https://github.com/calcom/cal.com

# 2. Нажми Fork (правый верхний угол)

# 3. Скачай к себе на компьютер:
git clone https://github.com/ТВОЙusername/cal.com
cd cal.com

# 4. Установи зависимости:
npm install

# 5. Скопируй файл настроек:
cp .env.example .env

# 6. Запусти локально для теста:
npm run dev
💡 Самый лёгкий деплой: Зайди на Railway.app, нажми "New Project" → "Deploy from GitHub" → выбери свой форк Cal.com. Railway сам всё настроит за 5 минут.

Как зарабатывать

Напиши в Direct стоматологам/юристам. Предложи: «Сделаю вам страницу онлайн-записи с вашим логотипом за 3 000 ₽ + 2 000 ₽/мес обслуживание». У тебя затраты — $6/мес хостинг, доход с 10 клиентов — 20 000 ₽/мес.

🖋 Ghost
Платформа для блога с платными подписками
⭐ 53k stars

Что это такое

Ghost — движок для блога с встроенной монетизацией. Как Boosty или Substack, но ты сам владелец — никаких комиссий платформе. Подписчики платят напрямую тебе через Stripe.

💰 1 000 подписчиков × 300 ₽ = 300 000 ₽/мес

Как запустить (самый простой способ)

# Способ 1 — через Docker (рекомендуется):
docker run -d --name ghost \   -e url=https://твойдомен.ru \   -p 2368:2368 \   ghost:latest

# Способ 2 — установка через npm:
npm install -g ghost-cli
ghost install
💡 Проще всего: Digital Ocean есть готовый «1-Click Ghost Droplet» — нажал кнопку, через 3 минуты твой Ghost уже работает. Стоит $6/мес.

Настройка платежей (Stripe)

# В панели Ghost Admin:
Settings → Membership → Connect Stripe account

# Создай тарифы подписки
Settings → Membership → Tiers → Add tier
# Пример: «Базовый» 200 ₽/мес, «Про» 500 ₽/мес

Как зарабатывать

Пиши полезный контент в своей нише (финансы, психология, бизнес). Часть постов — бесплатно, лучшие — только для подписчиков. Продвигай в Telegram и Instagram.

⚡ Supabase
База данных + API + авторизация за минуты
⭐ 104k stars

Что это такое

Supabase — это Firebase, но open-source. Даёт тебе базу данных PostgreSQL, авторизацию пользователей, хранилище файлов и автоматическое API. Идеально для создания SaaS-приложений без знания бэкенда.

💰 Собери приложение за выходные → продавай по 2 500 ₽/мес

Самый быстрый старт

# Вариант А — облако (бесплатно для старта):
1. Зайди на supabase.com
2. Sign up → New Project
3. Получаешь URL и ключи API
4. Используй в своём приложении

# Вариант Б — self-hosted (полный контроль):
git clone https://github.com/supabase/supabase
cd supabase/docker
cp .env.example .env
docker compose up -d

Пример использования в коде

# Установи SDK:
npm install @supabase/supabase-js

# В своём приложении:
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  'https://xxxxxx.supabase.co',
  'твой_публичный_ключ'
)

# Получить данные из таблицы:
const { data } = await supabase
  .from('products').select('*')
💡 Идея для бизнеса: Сделай простое SaaS-приложение (например, CRM для малого бизнеса, трекер задач, планировщик контента). Supabase берёт на себя всю техническую часть — тебе остаётся только фронтенд.

💌 Listmonk
Сервис email-рассылок — Mailchimp без абонентки
⭐ 21k stars

Что это такое

Mailchimp стоит 10 000–50 000 ₽/мес при большой базе. Listmonk ставишь на свой сервер (~500 ₽/мес) и делаешь неограниченные рассылки. Можешь продавать услуги рассылок другим бизнесам.

💰 Клиенты платят 2 000–5 000 ₽/мес, твои расходы — 500 ₽/мес

Запуск через Docker (5 минут)

# 1. Скачай docker-compose файл:
curl -LO https://github.com/knadh/listmonk/raw/master/docker-compose.yml

# 2. Запусти:
docker compose up -d

# 3. Открой в браузере:
http://localhost:9000

# Логин по умолчанию: listmonk / listmonk

Настройка SMTP (для отправки писем)

# В панели Listmonk:
Settings → SMTP → Add new SMTP server

# Используй один из сервисов:
- Amazon SES ($0.10 за 1000 писем) — самый дешёвый
- Brevo (бесплатно до 300 писем/день)
- Postmark (лучшая доставляемость)
⚠️ Важно: Для рассылок нужен свой домен с настроенными SPF, DKIM и DMARC записями. Иначе письма попадут в спам. Настрой это через панель управления своим доменом.

Как зарабатывать

Найди малый бизнес (магазины, рестораны, салоны), которые платят за Mailchimp или не делают рассылок вообще. Предложи вести их email-маркетинг. Стоимость для тебя = $6 сервер + $1-2 на SMTP. Продаёшь за 3 000–5 000 ₽/мес.

🛒 Medusa
Интернет-магазин без комиссий — альтернатива Shopify
⭐ 34k stars

Что это такое

Shopify берёт 2% с каждой продажи + $29–79/мес. Medusa — бесплатен, open-source, и все деньги остаются тебе. Идеально для создания магазинов под ключ для других бизнесов.

💰 Создавай магазины клиентам за 30 000–100 000 ₽

Как запустить

# 1. Установи Medusa CLI:
npm install -g @medusajs/medusa-cli

# 2. Создай новый проект:
medusa new my-store --seed

# 3. Перейди в папку и запусти:
cd my-store
medusa develop

# 4. Бэкенд работает на:
http://localhost:9000
# Панель администратора:
http://localhost:7001

Подключение платежей

# Stripe (международные платежи):
npm install @medusajs/payment-stripe

# В файле medusa-config.js добавь:
modules: [\{
  resolve: "@medusajs/payment-stripe",
  options: \{ apiKey: process.env.STRIPE_API_KEY \}
\}]
💡 Стратегия: Найди малый бизнес с Instagram-магазином, который устал принимать заказы в DM. Предложи полноценный сайт-магазин на Medusa. Бери 50 000 ₽ за создание + 5 000 ₽/мес за поддержку.
